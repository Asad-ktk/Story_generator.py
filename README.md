# 🎭 Mad Libs Story Generator

A simple Python **Mad Libs** program that asks the user for five words and creates a fun short story using them.

## 📌 About the Project

This project is a beginner-friendly Python program designed to practice:

* User input with `input()`
* Variables
* **f-strings**
* String formatting
* Aligned tables using formatting options

The program asks for a:

1. Noun
2. Verb
3. Adjective
4. Place
5. Number

It then uses these words to generate a short, funny story and displays the entered words in a neat table.

## 🛠️ Requirements

* Python 3.x
* No external libraries are required.

## 💻 Example

### Input

```text
Enter a noun: dragon
Enter a verb: fly
Enter an adjective: brave
Enter a place: Paris
Enter a number: 10
```

### Output

```text
--- Mad Libs Story ---
One day, a brave dragon decided to fly to Paris.
It took 10 hours, but the adventure was amazing!

--- Your Words ---
Type         Word
---------------------------
Noun         dragon
Verb         fly
Adjective    brave
Place        Paris
Number       10
```
